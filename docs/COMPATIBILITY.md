# CineForm Bitstream & Format Compatibility

This document details the format compatibility status, supported pixel/encoded formats, quality settings, and current verification scope for **HyperCine** (`phase3a2-release-candidate`).

---

## 1. Bitstream Compatibility Standard & Verification Status

HyperCine emits elementary bitstreams conforming to the **GoPro CineForm SDK** (`CFHD` FourCC) and **SMPTE ST 2073 (VC-5)** structure.

### Verified in Release-Candidate Automated Test Gate
- **Pristine Upstream GoPro CineForm SDK (`upstream/`):**
  - 100% of bitstreams generated by HyperCine's CUDA encoder (`src/core/phase3a_encoder.cpp`) are verified against the unmodified upstream `CFHD_EncodeSample` encoder (for dynamic `FSratelimiter`, quantizer table, subband coefficient, subband VLC payload, and masked sample byte identity) and decoded via the unmodified upstream `CFHD_DecodeSample` decoder (`tests/test_phase3a`, `tests/test_phase2d`, `tests/test_phase2c`).
  - Upstream sample AVI decoding (`upstream/Example/videos/CFHDsample422.AVI`) is verified in `tests/test_avi_sample`.

### External Ecosystem Interoperability Status (Not Yet Automated in CI)
While HyperCine's output samples are byte-for-byte identical (modulo volatile GUID/date/time/timecode tags, which match upstream tag structure) to samples produced by `CFHD_EncodeSample`:
- **FFmpeg (`cfhd` decoder):** Not yet part of the automated CTest suite.
- **Third-Party NLEs (Adobe Premiere Pro / After Effects, DaVinci Resolve, Apple Final Cut Pro):** Standalone AVI/MOV container muxing and NLE import validation are not yet included in this release candidate.

## 2. Supported Formats: HyperCine CUDA Encoder vs. Upstream Reference SDK

It is important to distinguish between formats implemented in the **HyperCine Phase 3A.2 CUDA GPU encoder** and formats supported by the **pristine upstream CPU reference SDK** (`CFHDCodecStatic`):

| Pixel Format FourCC | Memory Layout | Encoded Format | Upstream CPU SDK (`CFHDCodecStatic`) | HyperCine CUDA GPU Encoder (Phase 3A.2) |
| :--- | :--- | :--- | :---: | :---: |
| `CFHD_PIXEL_FORMAT_BGRA` (`'BGRA'`) | Packed 8-bit B, G, R, A | `CFHD_ENCODED_FORMAT_YUV_422` (10-bit internal) | Supported | **Implemented & Verified** (`1080p`, `4K UHD`, `8K UHD`, progressive, `GOP=1`, `FilmScan 3`) |
| `CFHD_PIXEL_FORMAT_YUY2` (`'YUY2'`) | Packed 8-bit Y0 U0 Y1 V0 | `CFHD_ENCODED_FORMAT_YUV_422` | Supported (Tested in `test_codec_roundtrip`, `test_yuy2_stability`) | Not yet accelerated on GPU |
| `CFHD_PIXEL_FORMAT_2VUY` (`'2vuy'`) | Packed 8-bit U0 Y0 V0 Y1 | `CFHD_ENCODED_FORMAT_YUV_422` | Supported | Not yet accelerated on GPU |
| `CFHD_PIXEL_FORMAT_BGRA` / `RGBA` | Packed 8-bit | `CFHD_ENCODED_FORMAT_RGB_444` / `RGBA_4444` | Supported | Not yet accelerated on GPU |
| `CFHD_PIXEL_FORMAT_RGB48` / `B64A` | Packed 16-bit RGB / BGRA | `CFHD_ENCODED_FORMAT_RGB_444` / `RGBA_4444` | Supported | Not yet accelerated on GPU |
| `CFHD_PIXEL_FORMAT_BYR2` / `BYR4` | Planar 10/12-bit Bayer RAW | `CFHD_ENCODED_FORMAT_BAYER` | Supported | Not yet accelerated on GPU |

## 3. Encoding Quality Presets & Rate Control

| Quality Preset | Value | Upstream CPU SDK | HyperCine CUDA GPU Encoder (Phase 3A.2) |
| :--- | :--- | :---: | :---: |
| `CFHD_ENCODING_QUALITY_FILMSCAN3` | FilmScan 3 | Supported | **Implemented & Verified** (with sequence-stateful `FSratelimiter` dynamic quantization matching upstream) |
| `FILMSCAN2`, `FILMSCAN1`, `HIGH`, `MEDIUM`, `LOW` | Lower bitrate presets | Supported | Not yet validated in GPU release gate (codebooks `cs9` without peaks are active in FilmScan 3) |

## 4. Resolution and Scan Mode Support in HyperCine CUDA Encoder

- **Validated Resolutions:**
  - **1080p Full HD** ($1920 \times 1080$)
  - **4K UHD** ($3840 \times 2160$)
  - **8K UHD** ($7680 \times 4320$)
  - Subband and transform tests also cover $128 \times 128$ and arbitrary padded row strides ($\text{pitch\_px} > \text{width}$).
- **Scan Mode & GOP:**
  - Progressive (`CFHD_ENCODED_FORMAT_PROGRESSIVE`), intra-frame (`GOP = 1`), 3 channels ($Y, U, V$), 3 wavelet decomposition levels (30 subbands per frame: 27 VLC-encoded highpass bands + 3 uncompressed 16-bit big-endian lowpass bands).
  - Interlaced field modes are not implemented on the GPU path.

## 5. Mathematical Precision & Determinism

### Wavelet Integer Arithmetic
- All 2-6 biorthogonal wavelet transforms compute using exact 16-bit and 32-bit integer arithmetic with symmetric rounding offsets, producing bit-exact coefficients matching the pristine upstream spatial wavelet transform.
- Floating-point arithmetic is not used in the wavelet, quantization, or VLC entropy pipeline.

### Metadata Determinism
- In normal operation (`deterministic_test_metadata = false`), each encoder session generates a fresh clip GUID (`TAG_CLIP_GUID`) and per-frame encode date/time/timecode tags (`TAG_ENCODE_DATE`, `TAG_ENCODE_TIME`, `TAG_TIMECODE`) plus monotonic `TAG_UNIQUE_FRAMENUM`.
- In deterministic verification mode (`deterministic_test_metadata = true`), the four volatile timestamp/GUID tags are normalized to fixed constants so full-sample SHA-256 hashes can be compared across runs and across input modes (`HostPageableEndToEnd`, `HostPinnedApi`, `DeviceInput`).
