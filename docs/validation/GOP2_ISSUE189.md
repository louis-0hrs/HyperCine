The 66 buffers per geometry comprise 51 resident logical band buffers and
15 reconstructed wavelet4-LL, temporal low/high, frame0/frame1 base-LL buffers.
They are copied from the actual original decoder's memory after its full inverse.
They are **not** advertised as pre-inverse coefficients. Original row padding is
removed; each sidecar retains original pitch and compact dimensions, channel,
wavelet, band, level, wavelet type, prescale and quantization.
No signed full-frame plane or stage was fabricated from HyperCine output.

The original encoder receives two deterministic, temporally asymmetric YUY2
frames generated by exporter version 1. These are explicitly generated sources,
not camera footage or imported historical fixtures. Sources are stored verbatim.
`CFHD_EncodeSample` is the original encoder; no HyperCine encoder is linked into
the collector. The packet is copied after the second input without metadata
normalization. It contains both frame indices of progressive YUV422 p10,
FilmScan3, `YUV_2FRAME_GOP` (flags 2). Input is 8-bit YUY2 video-range, top-down,
pitch `2*width`; this is distinct from the coded 10-bit precision.

## Reference control and provenance

- Frozen SDK revision: `11574d0295771edccadd17af14af74a539f924c7`.
  Repository upstream tree: `837528ef9e9a55c416e9592ecb54e1c8f1ff9cf8`.
  `upstream/` is unchanged. No scratch instrumentation was needed for these
  resident buffers. Typed private-member access observes the original SDK
  instance, following the existing `decode_phase0_support.h` research accessor.
- Collector base: `a987f67` (`origin/main` at collection). The exporter source,
  actual executable and original static SDK library SHA-256/length are pinned
  in every artifact sidecar. The collector additions were uncommitted when built;
  the explicit source digest, not the base SHA alone, identifies the exporter.
- Native AMD Ryzen 9 7940HS, Windows build 26200, MSVC 19.44.35229.0,
  Release `/O2`, C++17, CMake 3.31.6-msvc6. CUDA is disabled in the SDK collector.
- `TAG_CPU_MAX=1`, native `cpu_limit`/thread limit/capabilities set to 1,
  and process affinity restricted to one allowed CPU. Observed entropy pool:
  0; transform worker pool: 1; allowed CPUs: 1. The process ends with its own
  affinity; other processes are untouched. This bounded control does not fix
  or qualify the default/oversubscribed SDK decoder from #160.
- Per format and geometry: three fresh decoder instances in one process,
  each decoding the same packet three times (18 SDK decode calls per geometry
  across YU64/BGRA). Both frames are checked on each call; frame 1 uses the
  original `ReconstructSampleFrameToBuffer`. All compared frames are byte-stable.
  Resident stages are also compared across the three fresh YU64 instances.
  There is no claim of separate-process or default-pool repeatability.
- `srand(0x1337BEEF)` before each original encode/decode/reconstruction controls
  upstream rounding/dither separately from gross-corruption checks.
- Source vs decoded YU64 PSNR, full 255-code peak, must exceed 35 dB for both
  frames: 1080p **65.6262 / 65.6262 dB**; 4K **59.1782 / 59.1793 dB**.
  API success alone never qualifies an output; temporal asymmetry and repeated
  bytes must also hold. This source-quality check is separate from exact parity.
- Decoded YU64 is top-down, little-endian `Y0,V,Y1,U`, 10-bit code shifted left
  6, pitch `4*width`. Decoded BGRA is **bottom-up**, BT.709, computer-graphics
  RGB range, pitch `4*width`. The observations/1 `orientation` field describes
  source/YU64 storage; the artifact sidecars and manifest explicitly identify
  BGRA's bottom-up storage. No original file was flipped or rewritten.

## Exact candidate comparison

Candidate source `7ed4a82ed97598454c2680bd264dedf259e6e7dc` was checked out in a
second isolated worktree. Its production sources and upstream remain unchanged.
The external CMake include adds only a test adapter and rejects another SHA or
tracked production-source differences. Native CUDA 12.8.61, architecture 89,
RTX 4090 Laptop, driver 610.62. The GPU was idle before this bounded comparison.

For each geometry the adapter compared both frames' BGRA, explicitly clipped
packed YU64, 42 materialized resident bands per frame and 12 reconstructed
LL/temporal stages per frame: **112 exact byte comparisons**, all passing.
The matrix is also checked for missing/duplicate entries by the independent
Python indexer. It re-hashes reference and candidate bytes and records actual
executable/source/decoder-library/wavelet-library SHA-256 and lengths.
The strict candidate parser accepted 54 physical chunks, 51 coefficient bands
and 3 control records for each actual packet; this parser is labeled as a
candidate structural check, not an independent stage producer.

Frame 0 does not materialize logical bands 11–13 for frame 1; frame 1 does not
materialize bands 14–16 for frame 0. These are explicitly listed in the report,
and each is compared on its own frame. No required case was silently skipped.
On a mismatch the adapter records first byte, channel, wavelet/band and row/column.
Clipped YU64 equality does not establish unclipped signed-plane equality.

The original Stage-1 manifest preserves the gaps as known when sealed.
The subsequent comparison indices resolve its candidate/topology gaps; the
pre-inverse and final-signed-plane gaps remain. Production decoder code, APIs,
thresholds and upstream sources were not changed. No performance improvement,
full CUDA-suite requalification, default-SDK stability, release or merge is claimed.

## Build and reproducibility

Inventory first; only use new output directories for genuinely missing files.
The collector supports the two requested dimensions only and refuses an existing
output directory before creating source/packet bytes.

```powershell
python tools/gop2_reference_inventory.py inventory --out inventory-new.json
cmake -S . -B build -A x64 -DHYPERCINE_ENABLE_CUDA=OFF `
  -DHYPERCINE_BUILD_BENCHMARKS=OFF -DHYPERCINE_ORACLE_BUILD_REPORT=OFF
cmake --build build --config Release -j 2
# Only when those original references are actually absent:
build/tests/Release/gop2_reference_export.exe build/new-reference/1920x1080 1920 1080
build/tests/Release/gop2_reference_export.exe build/new-reference/3840x2160 3840 2160
# Bind HYPERCINE_GOLDEN_DIR to this NEW local staging parent for sealing:
python tools/gop2_reference_inventory.py seal --relative 1920x1080 `
  --binary build/tests/Release/gop2_reference_export.exe --source tools/gop2_reference_export.cpp
```

For the unchanged candidate checkout, pass this report branch's absolute
`tests/reference_gop2/candidate/CMakeLists.txt` as
`-DCMAKE_PROJECT_HyperCine_INCLUDE=...` while configuring CUDA with
`-DHYPERCINE_BUILD_TESTS=OFF -DHYPERCINE_BUILD_BENCHMARKS=OFF -DCMAKE_CUDA_ARCHITECTURES=89`.
Build target `gop2_candidate_compare`, then run
`gop2_candidate_compare ORIGINAL_REFERENCE_DIR NEW_OUTPUT_DIR WIDTH HEIGHT`.
The original reference must already pass `verify`; `seal-comparison` and
`verify-comparison` re-hash the original bytes independently.

Validation of this test-only change: full isolated native CPU Release build;
`ctest --test-dir build -C Release --output-on-failure`: **15/15 PASS, zero skips**,
including six integrity/path/no-overwrite/comparison-matrix unit methods.
