## Historical / Archive Benchmark Records

The JSON files in this directory (`benchmarks/results/*.json`), the preserved Phase 3A.2 release candidate (`benchmarks/phase3a2_release_candidate.json`), and the Phase 3A.1 dirty-tree study files (`benchmarks/phase3a1_*.json`) are preserved as **historical engineering records** from earlier development and audit phases.

> **Important:** Do not quote numbers from historical Phase 0 – Phase 3A.2 files as current headline performance. Always use [`../phase3a2a_release_candidate.json`](../phase3a2a_release_candidate.json) and [`../../docs/PHASE3A1_BENCHMARK_HARDENING.md`](../../docs/PHASE3A1_BENCHMARK_HARDENING.md).
