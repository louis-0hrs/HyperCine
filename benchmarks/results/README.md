## Historical / Archive Benchmark Records

The JSON files in this directory (`benchmarks/results/*.json`) and the Phase 3A.1 dirty-tree study files (`benchmarks/phase3a1_*.json`) are preserved as **historical engineering records** from earlier development and audit phases.

> **Important:** Do not quote numbers from historical Phase 0 – Phase 3A files (`benchmarks/results/*.json`) as current headline performance. Those earlier milestone files used different measurement boundaries, single-run snapshots, or unstabilized laptop boost states prior to the Phase 3A.1 benchmark hardening pass documented in [`../../docs/PHASE3A1_BENCHMARK_HARDENING.md`](../../docs/PHASE3A1_BENCHMARK_HARDENING.md).

### Historical Files Inventory
- `reference_windows_msvc.json` — Phase 0 pristine upstream CPU baseline snapshot.
- `cuda_wavelet_phase1.json` — Phase 1A standalone 2-6 CUDA wavelet kernel microbenchmarks.
- `cuda_wavelet_phase1b.json` — Phase 1B multi-level GPU wavelet pyramid & quantization timings.
- `hybrid_phase1c.json` — Phase 1C hybrid GPU-wavelet + CPU-entropy profiling records.
- `phase2a.json` — Phase 2A asynchronous pinned host-to-device transfer & multi-slot overlap experiments.
- `phase2b.json` — Phase 2B single-frame GPU highpass VLC entropy kernel development records.
- `phase2c.json` — Phase 2C pipelined multi-stream GPU entropy & consolidated D2H study.
- `phase2d.json` — Phase 2D CUDA Graph & slot policy exploration records.
- `phase3a_sequence.json` — Phase 3A multi-frame sequence correctness & pre-hardening benchmark log.
- `../phase3a1_canonical.json` and `../phase3a1_fresh_*.json` — Phase 3A.1 benchmark-hardening and process-order sensitivity records (captured prior to final clean-tree commit).
